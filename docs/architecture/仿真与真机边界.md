# AMMR 仿真与真机拆分（2026-09-05）

## 最终边界

| 工程 | 内容 | 依赖方向 |
|---|---|---|
| `ammr_teleop` | 统一 XR 控制入口、仿真/真机控制适配、公共 IK、AGX Recorder、两类回放、控制中心、lift 消息类型 | 运行时不导入 Isaac |
| `ammr_sim` | Isaac 运行时、USD/场景资产、三相机生产端、共享内存 Recorder | 依赖 `ammr_teleop` 数据契约 |

真机部署包由 `ammr_teleop/deploy/server.manifest` 和 `agx.manifest` 生成，
两个 manifest 均不包含 `ammr_sim`、`hardware_ws` 或设备驱动源码；同时排除
`src/ammr_teleop/sim`，所以真机部署不会导入仿真控制适配模块。

## 录制语义

Isaac 启动时默认创建并预热三路相机以及独立 Recorder 进程。XR 遥操作只有
带 `--record` 时才允许左 X/键盘 `s` 切换 episode；不带该参数时按键会打印
`REC_DISABLED`，不会意外录制。左 X 第一次开始，第二次停止并保存；左 Y
始终只负责机械臂回零。

仿真相机保存仍走强同步共享内存；三路 ZMQ 端口只作为显示和外部消费接口，
并共享同一 `bundle_sequence`。真机相机由 RealSense/Orbbec SDK 直接发布到
`55555/55556/55557`，AGX Recorder 本地订阅，服务器 XR 以最新帧模式远程订阅。
机械臂 state/action、控制门和录制服务继续使用 ROS 2。

## 路径优先级

显式 CLI/环境变量优先于 `configs/paths.yaml`，配置文件优先于内置默认值。
所有本机相对路径按各自工程根目录解析；所有 `agx_*` 相对路径在远端按 AGX
用户 `$HOME` 解析。设备驱动 overlay 为外部部署配置，不属于源码依赖。
