# AMMR 路径配置与验证

路径优先级：显式 CLI > 环境变量 > `configs/paths.yaml` > 内置默认值。
本机相对路径始终以 `ammr_teleop` 工程根目录为基准，不依赖当前工作目录。

| 配置键 | 环境变量 | 用途 |
|---|---|---|
| `kinematics_urdf` | `AMMR_URDF` | 双臂 IK 无网格 URDF |
| `data_root` | `AMMR_DATA_ROOT` | 真机本地数据根目录 |
| `log_root` | `AMMR_LOG_ROOT` | 日志根目录 |
| `ros_ws` | `AMMR_ROS_WS` | 仅含 lift 消息类型的 ROS 2 工作空间 |
| `teleop_python` | `AMMR_TELEOP_PYTHON` | XR 遥操作 Python |
| `agx_root` | `AMMR_AGX_ROOT` | AGX 上的项目路径 |
| `agx_data_dir` | `AMMR_AGX_DATA_DIR` | AGX 数据目录 |
| `agx_overlay_setup` | `AMMR_AGX_OVERLAY_SETUP` | 可选机器人驱动 overlay |
| `agx_camera_setup` | `AMMR_AGX_CAMERA_SETUP` | 可选独立相机 overlay |

`agx_*` 相对路径不会在服务器展开，而是在远端 AGX 按登录用户 `$HOME`
解析。当前配置使用 `yanjun/ammr_teleop`，登录用户为 `lin` 时得到
`/home/lin/yanjun/ammr_teleop`；这样既不写死用户名，又与实际部署目录一致。
两个 overlay 默认留空，ROS 包已装入系统环境时无需配置。相机已改为厂商 SDK
直接发布 ZMQ，不再需要相机 ROS overlay，`agx_camera_setup` 仅为旧部署兼容项。

当前推荐配置为：

```json
{
  "agx_root": "yanjun/ammr_teleop",
  "agx_data_dir": "yanjun/ammr_teleop/datasets/ammr_real_xr"
}
```

仿真资产、Isaac Python 和仿真数据路径已从本配置删除，改由
`../ammr_sim/configs/paths.yaml` 独立管理。

```bash
# 真机服务器检查
./scripts/ammr.sh check --real

# 通过统一入口检查独立仿真工程
./scripts/ammr.sh check --sim

# 查看解析结果
python3 src/ammr_teleop/common/paths.py
```
